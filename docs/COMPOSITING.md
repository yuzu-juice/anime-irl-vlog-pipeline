# Compositing

## Core Principle

Presence is created by:
- grounding
- shadows
- occlusion
- scale
- timing

NOT by photorealism.

## Composition Order

clean_plate
→ anime_character
→ contact_shadow
→ ambient_occlusion
→ foreground_occluders
→ grading
→ grain
→ export

## Important Rules

The anime character should remain anime.

Avoid:
- over-relighting
- photoreal integration
- excessive bloom
- realistic skin rendering

## Contact Shadows

Mandatory.

Even simple projected ellipse shadows strongly improve grounding.

## Foreground Occlusion

Extremely important.

Small foreground overlaps dramatically improve perceived presence.
